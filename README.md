# ⚡ Tokenia

Landing page de una tienda ficticia de tokens de IA. Proyecto de práctica hecho con HTML, CSS y JavaScript puro, desplegado en Vercel.

## Secciones

- Hero con llamada a la acción
- Beneficios
- Calculadora de tokens (recomienda un paquete según tu uso)
- Precios
- Preguntas frecuentes
- Registro por email (demo)

## Correr localmente

Abrí `index.html` en el navegador. No hace falta instalar nada.

## Deploy

Importá el repo en [vercel.com/new](https://vercel.com/new) → **Deploy**. Al ser un sitio estático, no necesita configuración.
